# 長者關懷小幫手

輕量 PWA，三大功能：

- **布告欄**：記事新增 / 標記完成 / 刪除（localStorage 持久化）
- **運動建議**：依部位隨機抽取建議（內容待整合）
- **佈置遊戲**：拖曳家具到房間佈置（localStorage 自動存檔）

## 啟動方式

無需建構工具，直接以瀏覽器或手機開啟 `index.html` 即可使用。
若要部署為 PWA，建議透過 HTTPS 提供，並使用任何靜態伺服器：

```bash
npx serve .
```

## 佈置遊戲操作

### 道具
- **點選道具**：顯示浮動選單（➕➖🗑✓）
- **拖曳道具**：移動到想放的位置（自動選取）
- **➕➖**：縮放 0.4–3.0 倍
- **🗑**：刪除該道具
- **點房間空白處**：取消選取

### 分類
- 全部 / 家具 / 植物 / 裝飾 / 動物 / 我的素材
- 道具以「橫向可滑動」方式呈現同分類道具

### 背景
- 5 種預設（客廳 / 臥室 / 花園 / 海邊 / 夜晚）
- 自訂顏色（色盤）
- 自訂圖片（會佔儲存空間，建議 < 1 MB）

### 自訂素材
- 點「新增我的素材」展開區塊，或到「我的素材」分類
- 點「＋ 上傳圖片」選圖檔（PNG/JPG/WebP，建議 < 500 KB）
- 上傳後在「我的素材」分類點擊即可加入房間
- 「清除全部」會刪除自訂素材與其道具

### 持久化
- 道具位置 / 縮放 / 背景 / 自訂素材 / 當前分類都自動寫入 localStorage
- 從舊版（v1）會自動遷移並補上 `scale: 1`
